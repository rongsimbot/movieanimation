## Episode 2: Writing & Parsing Your Script (5:20)
### Learning Objectives
- Write or upload a movie script
- Understand the script format that works best
- Use AI script parsing to break down scenes

### Script Outline
1. **Script Writing vs. Uploading (0:00-0:45)**
   - Two options: Write directly in editor OR upload file
   - Supported formats: PDF, DOCX, plain text
   - Demo: Upload a PDF script file → auto-extracted text

2. **Script Editor Deep Dive (0:45-2:15)**
   - Title and genre fields
   - Writing in the text editor
   - Formatting tips for best AI results
   - Save draft vs. submit

3. **AI Script Parsing (2:15-4:00)**
   - Click "Parse Script" → AI breaks into scenes
   - Show the parsing result: scenes, characters, chapters
   - Reviewing the breakdown for accuracy
   - Editing scene details if needed

4. **Tips & Best Practices (4:00-5:20)**
   - Use clear scene headings: "INT. LIVING ROOM - DAY"
   - Describe visual elements (lighting, mood, camera angles)
   - Keep scenes under 200 words
   - Common mistakes to avoid

### Screen Recording Checklist
- [ ] Prepare a sample script (synclair-demo-script.txt)

## Episode 3: Character Photos & Asset Management (2:50)
### Learning Objectives
- Upload character photos and assets
- Assign photos to script characters
- Organize the asset library

### Script Outline
1. **Why Character Photos Matter (0:00-0:30)**
   - AI uses photos to inject faces into generated scenes
   - Best practices: well-lit, front-facing, clear backgrounds

2. **Uploading Assets (0:30-1:30)**
   - Navigate to Assets tab
   - Drag-and-drop upload (JPG, PNG up to 10MB)
   - Multiple file upload at once
   - Asset type tagging (character photo, prop, background)

3. **Assigning Photos to Characters (1:30-2:20)**
   - Go to Characters tab
   - See auto-detected characters from script parsing
   - Click character → "Assign Image" → pick from asset library
   - Verify assignment

4. **Asset Library Management (2:20-2:50)**
   - Filter by type
   - Grid view for visual browsing
   - Delete and reorganize

## Episode 4: Generating AI Video Scenes (4:15)
### Learning Objectives
- Understand the AI generation pipeline
- Generate a video scene from a script scene
- Track generation progress and costs

### Script Outline
1. **How Video Generation Works (0:00-0:45)**
   - Script scene → prompt engineering → API call → video output
   - Available APIs: Sora, Runway, Seedance, Luma
   - Quality vs. cost tradeoffs

2. **Generating Your First Scene (0:45-2:00)**
   - Navigate to scene in Script Breakdown
   - Click "Generate Scene"
   - Select API preference (or use Smart Router)
   - Submit generation job

3. **Tracking Progress (2:00-3:00)**
   - Real-time progress bar
   - Estimated time remaining
   - Scene queue status

4. **Reviewing Generated Scenes (3:00-3:45)**
   - Preview the generated video
   - Regenerate if needed (with modified prompt)
   - Approve → ready for timeline

5. **Cost Awareness (3:45-4:15)**
   - Check Cost Dashboard
   - Understand per-generation costs
   - Budget management tips

## Production Notes

### Recording Setup
- **Tool:** OBS Studio (free, open-source)
- **Resolution:** 1920x1080, 30fps
- **Audio:** Clear voiceover (Blue Yeti or similar)
- **Cursor:** Highlight clicks and use smooth cursor movement

### Post-Production
- **Editor:** DaVinci Resolve (free) or CapCut
- **Add:** Intro bumper (MovieAnimation logo, 3s), outro (call to action, 5s)
- **Captions:** Burn-in captions for all key actions
- **Thumbnail:** Custom thumbnail per episode with episode number

### Publishing
- **Platform:** YouTube (unlisted for beta, public at launch)
- **Also Upload To:** MovieAnimation.ai/help embedded player
- **Description:** Include timestamps and links to related episodes

### Beta-Specific Notes
- Add "BETA" watermark in corner of all videos
- Include disclaimer: "Features shown may change before public launch"
- End each video with: "Found a bug? Let us know at support@movieanimation.ai"
