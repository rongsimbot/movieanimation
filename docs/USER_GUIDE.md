# MovieAnimation.ai — User Guide
## Create Movies with AI — Quick Start

**Welcome!** MovieAnimation.ai transforms your scripts into animated movies using artificial intelligence. Upload your story, add characters, and let AI handle the animation.

---

## 🚀 Quick Start (5 Minutes)

### Step 1: Create Your Account
1. Go to **https://movieanimation.ai**
2. Click **Sign Up**
3. Enter your email, name, and password
4. Verify your email (check spam folder)

### Step 2: Create Your First Project
1. Click **New Project** on the dashboard
2. Give it a title (e.g., "My Action Scene")
3. Add an optional description

### Step 3: Upload Your Script
1. Navigate to the **Script** tab
2. Write or paste your screenplay/script
3. Click **AI Parse** — our system breaks it into scenes and characters
4. Review the breakdown, make adjustments if needed

### Step 4: Add Character Images (Optional)
1. Go to the **Assets** tab
2. Upload photos of your characters (headshots work best)
3. Go to **Characters** tab
4. Assign uploaded images to each character
5. AI will inject character faces into generated videos

### Step 5: Generate Videos
1. Go to the **Scenes** tab
2. Click **Generate** on each scene — or **Generate All**
3. Choose AI provider (Auto is recommended for best results)
4. Wait for generation to complete (30s-3min per scene)
5. Review each generated clip

### Step 6: Assemble Your Movie
1. Go to the **Timeline** tab
2. Drag-and-drop generated clips in order
3. Add transitions: Cut, Fade, or Dissolve
4. Click **Assemble** to stitch everything together

### Step 7: Export & Share
1. Go to the **Export** tab
2. Select resolution (720p HD / 1080p Full HD / 4K)
3. Choose format (MP4 recommended)
4. Click **Export** — wait for processing
5. Download or create a shareable link

## 📝 Writing Scripts for AI

### Best Practices
- Keep scenes **5-10 seconds** of dialogue/action each
- Name characters consistently (e.g., "JOHN" not "John", "J", "johnny")
- Specify settings clearly: `INT. OFFICE - DAY` or `EXT. PARK - SUNSET`
- Each scene should focus on 1-2 characters for best AI results

### Example Script Format
```
INT. COFFEE SHOP - DAY

SARAH stirs her coffee, staring out the rainy window.

BEN approaches the table, holding his own cup.

BEN
Mind if I sit?

SARAH
(looking up)
It's a free country.
```

### Script Tips
- ✅ Simple dialogues with action beats
- ✅ Clear emotional states (angry, happy, sad)
- ✅ Single location per scene
- ❌ Avoid rapid action sequences
- ❌ Avoid scenes with 3+ characters
- ❌ Avoid complex special effects descriptions

## ✂️ Timeline Editor

### Adding Clips
- Drag from scene list to timeline
- Click + button on empty slots
- Import external videos via Assets

### Transitions
- **Cut:** Instant switch (best for fast pacing)
- **Fade:** Fade to black between scenes (dramatic pause)
- **Dissolve:** Smooth crossfade blend (dreamy transitions)

- Drag clips to rearrange

## 🆘 Troubleshooting

### Video generation failed?
- Check your internet connection
- Try a different AI provider
- Reduce scene complexity
- Wait a few minutes and retry

### Script not parsing correctly?
- Use standard screenplay format
- Add scene headers: `INT./EXT. LOCATION - TIME`
- Check character names are consistent
- Manually adjust in the Scene editor

### Timeline assembly stuck?
- Check all clips have finished generating
- Verify clip durations (each should be 3-10 seconds)
- Try Assembly again — FFmpeg may need a retry

### Export won't download?
- Ensure export status is "completed"
- Check browser download settings
- Try a different browser
- Clear cache and retry
